Microsoft 365 : fonctionnalités utiles à tester au travail

Mis à jour le 30 septembre 2026 5 min de lecture

Microsoft 365 regroupe des applications et des services dont les possibilités varient selon votre abonnement et votre organisation. Avant d’ajouter un outil, vérifiez les fonctions déjà disponibles dans Word, Excel, PowerPoint ou votre espace de fichiers. Quelques méthodes simples peuvent éviter les copies multiples et les corrections répétées.

Les exercices ci-dessous se réalisent sur des fichiers fictifs ou des copies de travail. Les chemins de menus peuvent différer entre Windows, Mac et le navigateur : utilisez la recherche de commandes si le libellé ne correspond pas à votre version.

1. Word : appliquer des styles aux titres

Un titre mis en gras et agrandi paraît lisible mais n’a pas nécessairement de fonction dans la structure du document. Les styles Titre 1 et Titre 2 permettent de conserver une hiérarchie cohérente. Microsoft présente leur application dans le guide Word pour nouveaux utilisateurs.

Exercice : créez un rapport avec trois sections et deux sous-sections. Appliquez Titre 1 aux sections et Titre 2 aux sous-sections depuis les styles de l’onglet Accueil. Modifiez ensuite le style de titre : tous les titres du même niveau doivent suivre la modification sans correction individuelle.

Ajoutez un sommaire automatique, déplacez une section puis actualisez-le. Le test est réussi si la hiérarchie et les numéros de page restent cohérents. Le guide des fonctions Word avancées décrit ce travail et la formation Word permet d’approfondir les documents professionnels.

2. Excel : préparer des imports avec Power Query

Power Query sert à importer et transformer des données, puis à réutiliser les étapes lors d’une actualisation. Il peut notamment modifier les types de colonnes et retirer des informations inutiles. Consultez la présentation officielle de Power Query et les sources disponibles selon la version d’Excel. Les connecteurs et opérations ne sont pas identiques sur toutes les plateformes.

Exercice : préparez un fichier CSV contenant Produit et Montant, avec trois valeurs 100, 200 et 150. Importez-le depuis l’onglet Données, vérifiez le séparateur et donnez à Montant un type numérique adapté. Chargez le résultat dans Excel : le total doit être 450.

Ajoutez une quatrième ligne de 50 dans le fichier source, enregistrez-le et actualisez la requête. Le total attendu est maintenant 500. Si le résultat reste à 450, vérifiez la source utilisée, la plage importée et l’état de l’actualisation. Ne corrigez pas seulement le tableau de sortie : une prochaine actualisation pourrait écraser la correction.

Pour un besoin de calcul et d’analyse, commencez par la formation Excel. Pour programmer des actions répétées dans le classeur, consultez la formation VBA. Le guide de choix Excel et VBA aide à préciser le niveau nécessaire.

3. PowerPoint : retrouver les objets avec le volet de sélection

Une forme invisible peut être cachée derrière une autre. Le volet de sélection affiche les objets d’une diapositive et aide à les sélectionner ou à modifier leur ordre. Microsoft décrit le parcours Accueil, Organiser, Volet de sélection dans son guide des objets superposés.

Exercice : placez une photo, un rectangle et un titre sur une diapositive. Faites volontairement passer le rectangle devant le titre, puis retrouvez ce dernier dans le volet. Remettez les objets dans l’ordre attendu. Le test est réussi si vous pouvez sélectionner le titre sans déplacer au hasard les autres éléments.

Pour prévenir le problème sur plusieurs diapositives, travaillez aussi avec les dispositions et le masque. Le guide PowerPoint propose un exercice de présentation en cinq diapositives ; la formation PowerPoint complète cet apprentissage.

4. OneDrive et SharePoint : consulter une version précédente

Quand un fichier Office est enregistré dans OneDrive ou SharePoint, l’historique peut permettre de consulter et restaurer une version antérieure. La disponibilité et la conservation des versions dépendent du service et de ses réglages ; cette fonction ne doit pas être supposée active sur un simple fichier local. Voir le guide Microsoft de l’historique des versions.

Exercice : sur un document de test en ligne, écrivez « version initiale », enregistrez, puis remplacez le texte. Ouvrez l’historique depuis le nom du fichier ou le menu disponible et consultez la première version. Vérifiez son contenu avant de la restaurer. En équipe, avertissez les personnes concernées : restaurer une ancienne version peut remplacer leurs modifications récentes.

Pour un document partagé, choisissez les destinataires et leur droit de lecture ou de modification. Testez le lien avec un compte autorisé plutôt que de supposer que tout collègue pourra l’ouvrir. Le lien vers un document commun évite les pièces jointes concurrentes, à condition que les accès soient correctement réglés.

5. Power Automate : décrire un processus avant de le lancer

Un flux cloud se construit autour d’un événement déclencheur et d’actions. Avant de le configurer, écrivez une règle simple : « lorsqu’un nouveau document de test arrive dans ce dossier, signaler son nom à la personne responsable ». Le guide Power Automate explique le principe des déclencheurs, connexions et actions.

Vérifiez les connecteurs accessibles avec votre licence et les règles de votre organisation. Pour un essai, utilisez un dossier et un destinataire de test. Contrôlez le cas normal, une donnée absente et un document déjà traité ; consultez le résultat de l’exécution et prévoyez comment désactiver le flux. Un traitement automatique qui échoue silencieusement peut laisser croire qu’une tâche a été faite.

Par quelle fonction commencer ?

  • Vous corrigez les mêmes titres : commencez par les styles Word.
  • Vous nettoyez régulièrement un export : évaluez Power Query sur votre version d’Excel.
  • Vous déplacez des objets pour les sélectionner : testez le volet de sélection PowerPoint.
  • Vous perdez le fil des corrections : vérifiez le fichier partagé et son historique.
  • Vous répétez une suite d’actions : décrivez le processus avant de choisir son outil.

Choisissez une seule tâche et vérifiez si elle devient plus fiable après quelques essais. Pour les fonctions d’assistance par IA, consultez le guide Copilot dans Microsoft 365. Pour travailler les applications elles-mêmes, comparez les programmes du catalogue bureautique et confirmez le logiciel, le niveau de départ et l’accompagnement prévus.
